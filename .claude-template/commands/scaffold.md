# Scaffold Project Structure

Create language-specific project structure.

## Prerequisite

This command requires a language boilerplate. Run `/init-project` first and choose a boilerplate (e.g., Python).

If you've already added a boilerplate, the `/scaffold` command should have been replaced with the language-specific version. Try restarting Claude Code.

## Available Boilerplates

| Language | Command to Add |
|----------|----------------|
| Python | `/init-project` → Choose "Python" |
| React | Coming soon |
| Go | Coming soon |

## Manual Setup (No Boilerplate)

If you're not using a boilerplate, create your project structure manually:

1. Create your source directory structure
2. Create your CLAUDE.md with project commands
3. Run `/prime` to verify setup
